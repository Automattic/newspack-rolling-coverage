# Docs screenshots

One row per image in `site/public/screenshots/`, plus the homepage video and its images. The **Command** column holds the `npm run shot` command that retakes the image, and **Before and after** lists any setup or cleanup around it. See [README.md](README.md) for the options, the demo site and the house settings.

Run every command from `site/`. `<site>` is the address of your screenshot site, such as `https://screenshots.local`. Start from a freshly seeded site: run the seed, then `wp cache flush`.

Setup and cleanup steps run with WP-CLI on the screenshot site. After any shot whose steps change content, reseed (and flush the cache again) before the next one. One step reseeding may not undo (it does when the seed created the layouts): the Check for Updates block added to the Clock layout for `blocks/check-for-updates-3`. The seed reuses layouts the site already has, so run that row's undo step.

`getting-started/install-the-plugin-1` is taken by hand from GitHub, not with a command.
