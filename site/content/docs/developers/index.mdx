title: Developers
description: Reference for developers who connect Rolling Coverage to other tools or change how it behaves.
---

This section is for developers. Editors and publishers don't need it to run a coverage.

It will explain how code can work with Rolling Coverage: reading and writing coverages and entries from other tools, and changing what the plugin does. Each part starts with what it's for, then shows how to use it.

What it will cover:

- **REST API**: read coverages and entries, and add entries, from another app or service.
- **Hooks**: actions and filters that change what the plugin does or add to it.
- **Constants**: settings a site can fix in code, such as turning features on or off.
- **Data**: how coverages and entries are stored.

Until these pages are written, the plugin repository's [contributing guide](https://github.com/Automattic/newspack-rolling-coverage/blob/trunk/.github/CONTRIBUTING.md) lists every route, hook, and constant.
