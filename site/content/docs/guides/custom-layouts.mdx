---
title: Make a custom layout
description: Design a layout with the site's own blocks, save it as a pattern, and use it on any coverage.
---

By the end of this page, you will have a custom layout that appears in the **Choose a layout** window next to the built-in ones.

A custom layout is a synced pattern in the **Rolling Coverage** category. Its only block is a Rolling Coverage block.

## Before you start

The **Rolling Coverage** category appears once someone has picked a built-in layout on any page. If it isn't there yet, pick a layout on a page first, then come back.

Set the category before adding the Rolling Coverage block. With the category set, the block opens as an editable layout with sample entries, starting from Bulletin.

<Callout type="warn" title="Keep the pattern to one block">
Don't pick a coverage inside the pattern, and don't add other blocks beside the Rolling Coverage block. The pattern then no longer counts as a layout.
</Callout>

## On a block theme

<Steps>
<Step>

### Add a pattern

Go to **Appearance > Editor > Patterns**. Select **Add Pattern**, then **Add Pattern** in the menu.

<Screenshot label="Site Editor Patterns screen, Add Pattern button highlighted" />

</Step>
<Step>

### Name it and set the category

Enter a **Name**. In **Categories**, pick **Rolling Coverage**. Leave **Synced** on. Select **Add**.

<Screenshot label="Add Pattern dialog with a name, the Rolling Coverage category, and Synced on" />

</Step>
<Step>

### Design the layout

Add a Rolling Coverage block. Edit the layout with the block settings and the blocks inside it.

</Step>
<Step>

### Save it

Select **Save**. The layout is ready to use.

</Step>
</Steps>

To start from a built-in layout instead, open the **Rolling Coverage** category in **Patterns**. Open a layout's **Actions** menu and select **Duplicate**. The copy keeps the category and stays synced. Rename it, then select **Duplicate**.

## On a classic theme

<Steps>
<Step>

### Add a pattern

Open the Patterns screen and select **Add Pattern**.

</Step>
<Step>

### Name it

Enter a **Name**, leave **Synced** on, and select **Create**.

</Step>
<Step>

### Set the category

In the **Settings** sidebar, under **Pattern Categories**, add **Rolling Coverage**. The category is in the sidebar only, not in the create dialog.

<Screenshot label="Pattern editor sidebar, Pattern Categories with Rolling Coverage added" />

</Step>
<Step>

### Design the layout

Add a Rolling Coverage block. Edit the layout with the block settings and the blocks inside it.

</Step>
<Step>

### Publish it

Select **Publish**.

</Step>
</Steps>

## Use the layout

<Steps>
<Step>

### Open the layout window

On the page that shows the coverage, select the Rolling Coverage block. Select **Choose**, or **Change Layout** in the **Layout** panel.

</Step>
<Step>

### Pick the custom layout

The custom layouts are listed after Alert, sorted by title. Select yours. If it isn't listed, reload the page's editor.

<Screenshot label="Choose a layout window, custom layout listed after Alert" />

</Step>
</Steps>

## Things to know

- Picking a built-in layout also changes some block settings, such as **Show**, **Number of entries**, and **When ended**. A custom layout changes none of them. Set them on the block.
- A built-in layout's entries have a Share button. To remove it from a custom layout, delete it.
- Follow Coverage isn't part of any built-in layout. Add it yourself if you want it. See the [Follow Coverage block](/docs/blocks/follow-coverage/).
- A custom layout needs a Full Story Entry to show breakout posts as cards. Duplicating a built-in layout keeps it. See [Full stories](/docs/guides/full-stories/).
