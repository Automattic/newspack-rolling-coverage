By the end of this page, an Administrator will have turned on key takeaways, and editors will be able to generate a summary of a coverage's latest entries.

The summary is a starting point. Generating it copies it, ready for an editor to paste into the page.

## What you need

- The WordPress AI plugin, installed and set up with a provider.
- An Administrator account, to turn the feature on and edit its instructions.

## Turn it on

<Steps>
<Step>

### Open the AI settings

In the dashboard, go to **Settings > AI**. Until key takeaways can run, **Rolling Coverage > AI** says what's missing and links to the screen that sets it up, such as **Go to AI Settings**.

</Step>
<Step>

### Enable the feature

Turn on **Rolling Coverage Key Takeaways**. Choose the provider and model if the page offers them.

<Screenshot label="The AI settings page, with the Rolling Coverage Key Takeaways switch turned on" src="/screenshots/guides/ai-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Approve it if asked

If **Rolling Coverage > AI** says **Approve Rolling Coverage for AI**, select **Go to Connector Approvals** and approve Rolling Coverage.

</Step>
</Steps>

## Generate a summary

<Steps>
<Step>

### Open the block settings

In the editor, select the Rolling Coverage block and open the **AI** panel. The panel appears once AI is set up and the block shows a coverage.

</Step>
<Step>

### Generate

Select **Generate Key Takeaways**. The summary appears under **Generated Output** and is copied, and the message "Key takeaways copied. Paste them into the page." appears.

<Screenshot label="The block settings AI panel, with the key takeaways shown under Generated Output" src="/screenshots/guides/ai-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Paste it

Paste the summary into the page, for example above the feed. Edit it before publishing.

To copy it again, select **Copy Generated Output**. If the browser didn't allow the copy, the message asks you to select it instead.

</Step>
</Steps>

The summary draws on the 20 most recent published entries, with pinned entries first. Generate again as new entries come in for an updated summary.

## Change the instructions

Administrators can change what the summary asks for.

<Steps>
<Step>

### Open the AI page

Go to **Rolling Coverage > AI**, or select **Edit the prompt** in the block's **AI** panel.

</Step>
<Step>

### Edit the prompt

Change the **Prompt** text, then select **Save**. The message "AI settings saved." appears.

To go back to the original wording, use the **More actions** menu and select **Reset**.

<Screenshot label="The Rolling Coverage AI page, with the Prompt field for Key Takeaways" src="/screenshots/guides/ai-3.webp" width={3024} height={1964} />

</Step>
</Steps>
