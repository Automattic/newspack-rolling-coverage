title: AI key takeaways

By the end of this page, an Administrator will have turned on key takeaways, and editors will be able to generate a summary of a liveblog's latest entries.

The summary is a starting point. The block copies it as soon as it's ready, for an editor to paste into the page.

## What you need

- The WordPress AI plugin, installed and set up with a provider.
- An Administrator account, to turn the feature on and edit its instructions.

## Turn it on

Until key takeaways can run, **Rolling Coverage > AI** says what's missing. When it can, it links to the screen that fixes it, such as **Go to AI Settings**.

<Steps>
<Step>

### Open the AI settings

In the dashboard, go to **Settings > AI**.

</Step>
<Step>

### Enable the feature

Turn on **Rolling Coverage Key Takeaways**. Choose the provider and model if the page offers them.

<Screenshot label="The AI settings page, with the Rolling Coverage Key Takeaways switch turned on" src="/screenshots/guides/ai-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Approve it if asked

If **Rolling Coverage > AI** says **Approve Rolling Coverage for AI**, select **Go to Connector Approvals** and approve Rolling Coverage.

</Step>
</Steps>

## Generate a summary

<Steps>
<Step>

### Open the block settings

In the editor, select the Rolling Coverage block and open the **AI** panel. The panel appears once AI is set up and the block shows a liveblog.

</Step>
<Step>

### Generate

Select **Generate Key Takeaways**. The summary appears under **Generated Output**, and the message "Key takeaways copied. Paste them into the page." confirms it's copied.

If the liveblog has no published entries yet, the message says "No published entries found for this liveblog." instead.

<Screenshot label="The block settings AI panel, with the key takeaways shown under Generated Output" src="/screenshots/guides/ai-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Paste it

Paste the summary into the page, for example above the feed. Edit it before publishing.

If the browser blocked the copy, the message says "Key takeaways generated. Select Copy Generated Output to copy them." instead. Select **Copy Generated Output** to copy the summary, or to copy it again later.

</Step>
</Steps>

The summary draws on the 20 most recent published entries, with pinned entries first. To update the summary as new entries come in, generate it again.

## Change the instructions

Administrators can change what the summary asks for.

<Steps>
<Step>

### Open the AI page

Go to **Rolling Coverage > AI**, or select **Edit the prompt** in the block's **AI** panel, which opens it in a new tab.

</Step>
<Step>

### Edit the prompt

Change the **Prompt** text, then select **Save**. The message "AI settings saved." appears.

To go back to the original wording, open the **More actions** menu, select **Reset to Defaults**, then select **Reset**.

<Screenshot label="The Rolling Coverage AI page, with the Prompt field for Key Takeaways" src="/screenshots/guides/ai-3.webp" width={3024} height={1964} />

</Step>
</Steps>
