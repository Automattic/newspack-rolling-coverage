By the end of this page, an Administrator will have turned on key takeaways, and editors will be able to generate a summary of a coverage's latest entries.

The summary is a starting point. The block writes it to a panel, and an editor copies it into the page.

## What you need

- The WordPress AI plugin, installed and set up with a provider.
- An Administrator account, to turn the feature on and edit its instructions.

## Turn it on

<Steps>
<Step>

### Open the AI settings

In the dashboard, go to **Settings > AI**.

</Step>
<Step>

### Enable the feature

Turn on **Rolling Coverage Key Takeaways**. Choose the provider and model if the page offers them.

<Screenshot label="AI settings page, Rolling Coverage Key Takeaways switched on" />

</Step>
<Step>

### Approve it if asked

If **Rolling Coverage > AI** says Rolling Coverage is waiting for AI connector approval, go to **Tools > Connector Approvals** and approve it.

</Step>
</Steps>

## Generate a summary

<Steps>
<Step>

### Open the block settings

In the editor, select the Rolling Coverage block. The **AI** panel appears once AI is set up on the site.

</Step>
<Step>

### Generate

Select **Generate Key Takeaways**. The summary appears under **Generated Output**.

<Screenshot label="The block settings AI panel, with the key takeaways shown under Generated Output" src="/screenshots/guides/ai-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Copy it

Select **Copy**, then paste the summary into the page, for example above the feed. Edit it before publishing.

</Step>
</Steps>

The summary draws on up to 20 published entries, pinned entries first.

## Change the instructions

Administrators can change what the summary asks for.

<Steps>
<Step>

### Open the AI page

Go to **Rolling Coverage > AI**.

</Step>
<Step>

### Edit the prompt

Change the **Prompt** text, then select **Save**. The message "AI settings saved." appears.

To go back to the original wording, use the **More actions** menu and select **Reset**.

<Screenshot label="The Rolling Coverage AI page, with the Prompt field for Key Takeaways" src="/screenshots/guides/ai-3.webp" width={3024} height={1964} />

</Step>
</Steps>
