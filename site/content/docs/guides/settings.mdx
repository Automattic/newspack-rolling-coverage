title: Settings
description: Rename statuses and labels for the whole site, such as calling entries updates, and set up Slack and AI.
---

All Rolling Coverage settings are on one page: **Rolling Coverage > Settings**, with **General**, **Slack**, and **AI** tabs. The **General** tab holds the wording readers see across every liveblog: what entries are called, the status labels, and two button labels. Use it to match the newsroom's own words.

Editors and administrators see the **General** tab. The **Slack** and **AI** tabs need an Administrator account.

## Open Settings

<Steps>
<Step>

### Open Settings

Go to **Rolling Coverage > Settings**. The page opens on the first tab you can use.

<Screenshot label="The Rolling Coverage Settings page on the General tab, with the Entry Name, Jump to Latest, Full Story, and Coverage Status sections" src="/screenshots/guides/settings-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Save

Change the fields, then select **Save** at the top of the page. The message "Settings saved." appears. **Save** works only after something on the tab has changed.

If you switch tabs, go back or forward in the browser, or leave the page before saving, a message asks first. Select **Discard Changes** to leave without saving, or **Cancel** to stay.

</Step>
</Steps>

An empty field goes back to its default.

## General tab

### Entry Name

Sets what the site calls entries. Write each word as it reads mid-sentence, for example "update" and "updates".

- **Singular**: one entry, up to 30 characters.
- **Plural**: several entries, up to 30 characters.

Fill in both or neither. The name shows in counts such as "3 new updates", in the empty feed message, and in the notice above an archived entry. Leave both empty to use "entry" and "entries".

### Jump to Latest

Sets the text of the button that takes readers back to the live feed. When it can, the button counts the new entries instead.

- **Button label**: up to 40 characters. The default is "Jump to latest".

### Full Story

Sets the label shown on an entry once its breakout post is published.

- **Full story label**: up to 40 characters. The default is "Full story".

Each breakout post can set its own label in the post editor. See [Full stories](/docs/guides/full-stories/).

### Coverage Status

Sets the text of the status badge for each status:

- **Live label**
- **Paused label**
- **Ended label**

For example, "Developing", "On hold", and "Closed". Each label can be up to 40 characters.

A Coverage Status block can set its own labels, which override these. See the [Coverage Status block](/docs/blocks/coverage-status/).

## Slack tab

Sets which Slack messages become entries and how they look: **Ignore prefix**, **Publish emoji**, **Draft emoji**, and **Highest heading**. It also shows the **Bot User** that entries from Slack are credited to. See [Slack](/docs/guides/slack/).

Until Slack is connected, the tab shows the same **Connect to Slack** steps as **Rolling Coverage > Slack Connection**. After **Verify & Connect**, the settings appear.

## AI tab

Sets the prompt the AI follows for key takeaways. See [AI key takeaways](/docs/guides/ai-key-takeaways/).

## Where settings take effect

Pages served from a cache show a change once the cache refreshes. Pages loaded after that show the new wording.
