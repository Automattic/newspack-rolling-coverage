title: Settings
description: Rename statuses and labels for the whole site, such as calling entries updates.
---

Settings holds the wording readers see across every coverage: what entries are called, the status labels, and two button labels. Use it to match the newsroom's own words.

Changing settings needs an Editor or Administrator account.

## Open Settings

<Steps>
<Step>

### Open All Coverages

Go to **Rolling Coverage > All Coverages**.

</Step>
<Step>

### Select Settings

Select **Settings** in the header. A window opens with two tabs: **Labels** and **Coverage Status**.

<Screenshot label="The Settings window on the Labels tab, with the Entry Name, Jump to Latest, and Full Story fields" src="/screenshots/guides/settings-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Save

Change the fields below, then select **Save**. The message "Saved." appears. Select **Cancel** to close without saving. If there are unsaved changes, the window asks before discarding them.

</Step>
</Steps>

An empty field goes back to its default.

## Labels tab

### Entry Name

Sets what readers see entries called. Write each word as it reads mid-sentence, for example "update" and "updates".

- **Singular**: one entry, up to 30 characters.
- **Plural**: several entries, up to 30 characters.

Fill in both or neither. The name shows in counts such as "3 new updates", in the empty feed message, and in the notice above an archived entry. Leave both empty to use "entry" and "entries".

### Jump to Latest

Sets the text of the button that takes readers back to the live feed. When it can, the button counts the new entries instead.

- **Button label**: up to 40 characters. The default is "Jump to latest".

### Full Story

Sets the label shown on an entry once its breakout post is published.

- **Full story label**: up to 40 characters. The default is "Full story".

Each breakout post can set its own label in the post editor. See [Full stories](/docs/guides/full-stories/).

## Coverage Status tab

Sets the text of the status badge for each status:

- **Live label**
- **Paused label**
- **Ended label**

For example, "Developing", "On hold", and "Closed". Each label can be up to 40 characters.

A Coverage Status block can set its own labels, which override these. See the [Coverage Status block](/docs/blocks/coverage-status/).

## Where settings take effect

Pages served from a cache show a change once the cache refreshes. Pages loaded after that show the new wording.
