title: Placements

Placements lists every page, template, widget area, and pattern that shows a coverage. Use it to find where a coverage appears before you change or end it.

## Open the list

In **Rolling Coverage > All Coverages**, open the coverage's row actions and select **Placements**. On a coverage's entries screen, the **Placements** button in the header does the same.

A coverage that no page shows, and that has no canonical URL, has no **Placements** option.

## What the list shows

Each row shows:

- what the place is, such as a page, a template, or a widget area;
- its title, with a **View** link for places readers can visit;
- the blocks that show the coverage, one per line, such as "Rolling Coverage (Ticker)" or "Coverage Status".

The title links to the editor for people who can edit that place. For everyone else it is plain text.

A feed set to show only the latest entries lists how many it shows, as in "Rolling Coverage (Ticker, latest 5)". A block detached from its layout shows "Detached" in place of the layout name.

The list covers published posts and pages, block templates, template parts, synced patterns, and widget areas.

A template that shows the coverage on its breakout posts is marked "Breakout posts", as in "Template · Breakout posts". Its **View** link opens the newest breakout post.

## The main page

The main page is the coverage's home. Links to an entry, including shared ones, open there, at that entry.

The main page sits at the top of the list. "Main" follows what the place is, as in "Page · Main".

The main page is the coverage's **Canonical URL**. To set it, do either of these:

- In the Rolling Coverage block on the page, open the **Coverage** panel and select **Use This Page**. Save the page first, so it has an address.
- In **All Coverages**, edit the coverage and fill in **Canonical URL**.

If the canonical URL matches no page in the list, it still gets a row at the top. That row is marked "Main page" and has only a **View** link.

Without a canonical URL, a link to an entry opens the entry's own page.
