---
title: Edit, detach, and restore a layout
description: Change a shared layout for every page that uses it, detach it for one page, or get a built-in layout back.
---

By the end of this page, you will know how to change a layout for every page that uses it, change it for one page only, and restore a built-in layout.

## How shared layouts work

The first time an Author, Editor, or Administrator picks a built-in layout, the site saves it as a shared layout. Every page that uses it then follows that one copy.

The block's **Layout** panel says which one it uses, for example "Uses the shared Rail layout". A Contributor who picks a layout before it has been saved gets a copy for that page only.

## Change the layout for every page

<Steps>
<Step>

### Select the block

In the editor, select the Rolling Coverage block.

</Step>
<Step>

### Open the layout editor

Select **Edit Layout** in the block toolbar. The shared layout opens in a new tab. It shows sample entries, so every part of an entry is visible.

Only people who can edit patterns see this button. On a block theme, it opens the Site Editor.

<Screenshot label="The Rolling Coverage block toolbar, with the Edit Layout button picked out" src="/screenshots/guides/edit-a-layout-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Make the change

Change the spacing, colors, type, or blocks inside the layout, as with any other blocks.

<Screenshot label="The Rail layout open in the Site Editor, showing sample entries and the Pattern Categories panel" src="/screenshots/guides/edit-a-layout-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Save it

Save the layout. Every page that uses it shows the change.

</Step>
</Steps>

<Callout type="warn" title="Edit Layout changes every page">
A shared layout is one copy. A change made with **Edit Layout** reaches every page that uses it. Once you edit a built-in layout, plugin updates no longer change it.
</Callout>

## Change the layout for one page only

<Steps>
<Step>

### Detach the layout

Select the block, then select **Detach** in the block toolbar. The layout is copied into this page. The **Layout** panel now reads "Uses its own layout, detached from the shared one."

<Screenshot label="The Rolling Coverage block toolbar, with the Detach button picked out" src="/screenshots/guides/edit-a-layout-3.webp" width={3024} height={1964} />

</Step>
<Step>

### Edit the block

Change the block's design and settings. The changes affect this page only. Later changes to the shared layout, and plugin updates, no longer reach it.

</Step>
</Steps>

## Switch to another layout

Open the **Layout** panel and select **Change Layout**. The **Choose a layout** window opens. Picking a layout replaces the current one, including a detached copy. The block keeps its coverage. Picking a layout sets **Show**, **Number of entries**, **When ended**, and **Author avatar** the way that layout sets them, so check them afterwards.

## Restore a built-in layout

A built-in layout keeps up with the plugin until someone edits it, so a plugin update brings its new design to every page that uses it. Settings such as **Show** and **When ended** stay as each block has them. Saving a change makes the layout your site's own, and updates no longer change it. Renaming it from the Patterns list doesn't count as a change.

To get the plugin's version of an edited layout back, delete its pattern and pick the layout again. This also brings back parts added since the layout was edited, such as the [New Label](/docs/blocks/new-label/) block that marks new entries.

Every page, template, widget area, and pattern that uses the layout shows Bulletin until you pick the layout again on each one. Before you delete it, open [Placements](/docs/guides/placements/) for each coverage that uses the layout, and note every block listed with it, such as "Rolling Coverage (Rail)". Placements lists only published content, so also check drafts, scheduled posts, and private pages.

<Steps>
<Step>

### Delete the layout's pattern

On a block theme, go to **Appearance > Editor > Patterns**, open the **Rolling Coverage** category, and delete the layout. This can't be undone.

On a classic theme, open the Patterns screen and trash the layout.

<Screenshot label="The Site Editor Patterns view filtered to the Rolling Coverage category, with the actions menu of the Rail layout open and showing Delete, Edit, Duplicate and other actions" src="/screenshots/guides/edit-a-layout-4.webp" width={3024} height={1964} />

</Step>
<Step>

### Reload the editor

Reload every editor tab that was open before you deleted it.

</Step>
<Step>

### Pick the layout again

Select **Change Layout** and choose the layout, then save. The site saves a fresh copy of the layout, which keeps up with the plugin again. Picking a layout sets **Show**, **Number of entries**, **When ended**, and **Author avatar** the way that layout sets them, so check them afterwards.

</Step>
<Step>

### Pick it on the other pages

Pick the layout again on every other page, template, widget area, and pattern that used it, and save each one.

</Step>
</Steps>

## If a layout is deleted by mistake

If a page points at a layout that no longer exists, readers see Bulletin. The editor asks you to choose a layout again.
