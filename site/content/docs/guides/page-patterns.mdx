---
title: Page patterns
description: Nine ready-made pages for a liveblog, what each one is for, and how to add one.
---

A page pattern is a page already laid out with the Rolling Coverage blocks. You add one, write your own text, and pick a liveblog. This page lists the nine patterns and when to use each one.

## Add a pattern

<Steps>
<Step>

### Open the patterns

In the editor, select the **Block Inserter** button, then the **Patterns** tab. Select **Rolling Coverage - Pages**.

<Screenshot label="The Patterns tab of the block inserter, with the Rolling Coverage - Pages category open" src="/screenshots/guides/page-patterns-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Select a pattern

Select a pattern to add it to the page. The patterns don't appear in the **Choose a pattern** window that opens on a new page. Add them from the inserter instead.

</Step>
<Step>

### Pick the liveblog and write your text

The Rolling Coverage block asks which liveblog to show. Search for it and select it. Then replace the placeholder text with your own.

</Step>
</Steps>

The page's own title is the headline. None of the patterns adds a second one.

Some patterns use the Coverage Status, Follow Coverage or Scoreboard block outside the feed. They follow the liveblog you pick in the page's Rolling Coverage block. See [Which liveblog a block shows](#which-liveblog-a-block-shows).

## Live page

A liveblog page that leads with its status. It has the Live badge with the time of the last update, a sentence that sums up the story, and the feed in the Clock layout, where each entry starts with the time it was posted.

Use it for a story where the time of each update is the point, such as election results or travel delays.

<Screenshot label="The Live page pattern on a page, with the Live badge, a sentence and the feed in the Clock layout" src="/screenshots/guides/page-patterns-2.webp" width={3024} height={1964} />

## Live page, latest first

The Live badge with the time of the last update sits at the top, with a **Get alerts** button on the same line. Below them, every entry shows in the Stream layout, newest first.

Use it when readers who arrive late want the latest news first, with a way to get alerts close at hand.

<Screenshot label="The Live page, latest first pattern on a page, with the Live badge and Get alerts button above the feed" src="/screenshots/guides/page-patterns-3.webp" width={3024} height={1964} />

## Live page with side column

A narrow column on the right, a third of the page, holds a box with a short heading, a sentence about alerts and a **Get alerts** button. The feed takes the rest. The Live badge and the time of the last update sit above both columns. Without the Newspack Blocks plugin, the narrow column is on the left.

On a phone the columns stack with the alerts box first, so readers see it without scrolling past the entries.

The columns are wider than the text column the theme puts the page title in. To line the title up with them, choose a wide page template in the page's **Template** setting, such as **Page (Wide)** on the Newspack Block Theme.

Use it for a busy liveblog page on desktop, where readers keep the page open.

<Screenshot label="The Live page with side column pattern on a page, with the badge above the columns, the feed on the left and the alerts box on the right" src="/screenshots/guides/page-patterns-4.webp" width={3024} height={1964} />

## Match: scoreboard beside the feed

A page for a match. A narrow column on the right, a third of the page, holds the Scoreboard, with the status line as a badge above the teams and a thin outline in the theme's separator color. The feed takes the rest, in the Minute layout, under a **Get alerts** button. Without the Newspack Blocks plugin, the narrow column is on the left.

The Scoreboard shows the score you set at the top of the liveblog's entries list, with a row for each team. It stays hidden until the liveblog has a score. See [Scoreboard](/docs/blocks/scoreboard/).

Both Match patterns set the scores in the theme's accent color and show the score's status line, such as "Full time", as a badge. Pick its style in the **Badge** menu next to **Status** in the liveblog's score row. Since that badge says where the match is, the patterns leave out the Coverage Status block and turn off the notice that a liveblog has ended. To show the notice, select the Rolling Coverage block and set **Notice** to **Show** in the **Ended** panel.

With the Newspack Block Theme, the score stays in view on wider screens while the feed scrolls; on a theme without sticky positioning, such as the classic Newspack Theme, it scrolls with the page. On a phone the columns stack with the score first, then the feed. As with the side column page, choose a wide page template to line the page title up with the columns.

Use it for a match where readers want the score beside the updates.

<Screenshot label="The Match: scoreboard beside the feed pattern on a page, with the feed on the left and the score on the right" src="/screenshots/guides/page-patterns-5.webp" width={3024} height={1964} />

## Match: centered scoreline

A page for a match that leads with the score. The team names and the scores sit large on one line, each team in its own half of the page, with the dash in the exact middle. The status line, such as "Second half", sits under them as a badge. Below is the feed in the Minute layout.

Use it when the score is the story, such as a final or a derby.

<Screenshot label="The Match: centered scoreline pattern on a page, with a large score above the feed" src="/screenshots/guides/page-patterns-6.webp" width={3024} height={1964} />

## Breaking news

An article with the latest update in a bar above the text. It has a sentence that sums up the story, the Rolling Coverage block in the Flash layout, and three paragraphs for the article. The bar links to the liveblog page with "See all entries", or the site's own word for entries.

The bar disappears once the liveblog ends, so the article reads as a normal article afterward.

Use it in a post or a page when a story is breaking and you want readers to see the newest update before the article text. The bar needs a liveblog with its own page, so readers have somewhere to follow the link.

<Screenshot label="The Breaking news pattern on a page, with the latest update in a bar above the article text" src="/screenshots/guides/page-patterns-7.webp" width={3024} height={1964} />

## Follow page

A page that asks readers to follow a liveblog. It has a sentence, the **Get alerts** button, three short columns that explain how alerts work, and the three latest updates in the Digest layout under the heading "Latest updates".

The columns are "An alert when it matters", "No account needed" and "Stop anytime". Each fits how the button works: readers get an alert for entries marked to send one, the browser asks for permission the first time, and selecting the button again turns them off. Keep them in line with how your site works if you change them.

<Screenshot label="The Follow page pattern on a page, with the Get alerts button, three columns of text and a box of latest updates" src="/screenshots/guides/page-patterns-8.webp" width={3024} height={1964} />

## Follow band

A full-width band with a heading and the Live badge beside it, a sentence and the **Get alerts** button. Under it, the five latest updates show in the Wire layout, with a "See all entries" link.

Use it to put a **Get alerts** button on a page that does more than one thing, or on a landing page for a story. The band takes its background from the theme, so change it in the Group block's **Styles** tab.

<Screenshot label="The Follow band pattern on a page, with a shaded band above a list of the five latest updates" src="/screenshots/guides/page-patterns-9.webp" width={3024} height={1964} />

## Every live story

A page that lists several liveblogs. It has a sentence and three rows. Each row has a heading for the liveblog's name, its Live badge, a line about it and a **Get alerts** button on the right.

The rows have no feed, so each row's Coverage Status and Follow Coverage blocks need their own liveblog. In each row, select the Coverage Status block, set **Liveblog** to **Custom** and pick a liveblog. Do the same for the Follow Coverage block. Until you do, the editor shows a sample badge and button, and the site shows nothing. Type the liveblog's name into the heading yourself. Copy a row to add more.

Use it as the page readers land on when you run several liveblogs at once.

<Screenshot label="The Every live story pattern on a page, with a row for each liveblog and a Get alerts button on the right of each" src="/screenshots/guides/page-patterns-10.webp" width={3024} height={1964} />

## Which liveblog a block shows

The Coverage Status, Follow Coverage, Update Timer and Scoreboard blocks set to **Automatic** use the first Rolling Coverage block on the page that shows every entry. If there is none, on a breakout post they use the liveblog the post came from, and otherwise the first one that shows only the latest entries, such as the Digest or Wire layout. So the Follow page and the Follow band work as soon as you pick the liveblog in their feed.
