title: Page patterns
description: Seven ready-made pages for a liveblog, what each one is for, and how to add one.
---

A page pattern is a page already laid out with the Rolling Coverage blocks. You add one, write your own text, and pick a liveblog. This page lists the seven patterns and when to use each one.

## Add a pattern

<Steps>
<Step>

### Open the patterns

In the editor, select the **Block Inserter** button, then the **Patterns** tab. Select **Rolling Coverage pages**.

<Screenshot label="The Patterns tab of the block inserter, with the Rolling Coverage pages category open" src="/screenshots/guides/page-patterns-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Select a pattern

Select a pattern to add it to the page. The patterns don't appear in the **Choose a pattern** window that opens on a new page. Add them from the inserter instead.

</Step>
<Step>

### Pick the liveblog and write your text

The Rolling Coverage block asks which liveblog to show. Search for it and select it. Then replace the placeholder text with your own.

</Step>
</Steps>

The page's own title is the headline. None of the patterns adds a second one.

Some patterns use the Coverage Status or Follow Coverage block outside the feed. Where a pattern says so below, select each of those blocks, set **Liveblog** to **Custom**, and pick the liveblog. Without that, the block shows nothing on the site. See [Which liveblog a block shows](#which-liveblog-a-block-shows).

## Live page

A liveblog page that leads with its status. It has the Live badge with the time of the last update, a sentence that sums up the story, and the feed in the Clock layout, where each entry starts with the time it was posted.

Use it for a story where the time of each update is the point, such as election results or travel delays.

<Screenshot label="The Live page pattern on a page, with the Live badge, a sentence and the feed in the Clock layout" src="/screenshots/guides/page-patterns-2.webp" width={3024} height={1964} />

## Live page, latest first

The newest entry shows large at the top, under the Live badge. Below it, under the heading "All updates", every entry shows in the Stream layout. The newest entry shows in both places.

Use it when readers who arrive late want the latest news first and the full record second.

<Screenshot label="The Live page, latest first pattern on a page, with the newest entry above the full feed" src="/screenshots/guides/page-patterns-3.webp" width={3024} height={1964} />

## Live page with side column

The feed sits on the left, two thirds of the page. On the right are the Live badge with the time of the last update, a **Follow** button and the Update Timer.

On a phone the columns stack. The Live badge and the **Follow** button move above the feed, so readers see them without scrolling past the entries. The pattern holds a second copy of both for this. One copy is hidden on large screens and the other on small ones, so edit both when you change them.

Use it for a busy liveblog page on desktop, where readers keep the page open.

<Screenshot label="The Live page with side column pattern on a page, with the feed on the left and the badge, Follow button and timer on the right" src="/screenshots/guides/page-patterns-4.webp" width={3024} height={1964} />

## Breaking news

An article with the latest update in a bar above the text. It has a sentence for the standfirst, the Rolling Coverage block in the Flash layout, and three paragraphs for the article. The bar links to the liveblog page with "See all entries", or the site's own word for entries.

The bar disappears once the liveblog ends, so the article reads as a normal article afterward.

Use it in a post or a page when a story is breaking and you want readers to see the newest update before the article text. The bar needs a liveblog with its own page, so readers have somewhere to follow the link.

<Screenshot label="The Breaking news pattern on a page, with the latest update in a bar above the article text" src="/screenshots/guides/page-patterns-5.webp" width={3024} height={1964} />

## Follow page

A page that asks readers to follow a liveblog. It has a sentence, the **Follow** button, three short columns that explain how alerts work, and the three latest updates in the Digest layout under the heading "Latest updates".

The columns are "An alert when it matters", "No account needed" and "Stop anytime". Each fits how the button works: readers get an alert for entries marked to send one, the browser asks for permission the first time, and selecting **Following** stops the alerts. Keep them in line with how your site works if you change them.

The Digest layout shows only the latest entries, so the **Follow** button can't find the liveblog on its own. Pick it in the Rolling Coverage block and in the Follow Coverage block.

<Screenshot label="The Follow page pattern on a page, with the Follow button, three columns of text and a box of latest updates" src="/screenshots/guides/page-patterns-6.webp" width={3024} height={1964} />

## Follow band

A full-width band with a heading, the Live badge, a sentence and the **Follow** button. Under it, the five latest updates show in the Wire layout, with a "See all entries" link.

Use it to put a **Follow** button on a page that does more than one thing, or on a landing page for a story. The band takes its background from the theme, so change it in the Group block's **Styles** tab.

Like the Follow page, it needs the liveblog picked in the Rolling Coverage, Coverage Status and Follow Coverage blocks.

<Screenshot label="The Follow band pattern on a page, with a shaded band above a list of the five latest updates" src="/screenshots/guides/page-patterns-7.webp" width={3024} height={1964} />

## Every live story

A page that lists several liveblogs. It has a sentence and three rows. Each row has a heading for the liveblog's name, its Live badge, a line about it and a **Follow** button on the right.

The rows start without a liveblog. In each row, select the Coverage Status block, set **Liveblog** to **Custom** and pick a liveblog. Do the same for the Follow Coverage block. Until you do, the editor shows a sample badge and button, and the site shows nothing. Type the liveblog's name into the heading yourself. Copy a row to add more.

Use it as the page readers land on when you run several liveblogs at once.

<Screenshot label="The Every live story pattern on a page, with a row for each liveblog and a Follow button on the right of each" src="/screenshots/guides/page-patterns-8.webp" width={3024} height={1964} />

## Which liveblog a block shows

The Coverage Status, Follow Coverage and Update Timer blocks set to **Automatic** use the first Rolling Coverage block on the page that shows more than the latest entries. A feed in the Digest, Wire, Flash, Ticker or Alert layout shows only the latest entries, so it doesn't count. That is why the Follow page and the Follow band need **Custom**, and why the other patterns work without it.
