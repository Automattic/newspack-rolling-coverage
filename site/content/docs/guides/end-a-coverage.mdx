title: End a liveblog
description: Set a liveblog to Ended, and choose what readers see on pages that show it.
---

By the end of this page, you will have ended a liveblog and chosen what readers see once the story is over.

Ending a liveblog needs an Editor or Administrator account.

## End the liveblog

<Steps>
<Step>

### Edit the liveblog

In **Rolling Coverage > All Liveblogs**, open the liveblog's row actions and select **Edit**. A panel opens on the right.

<Screenshot label="The row actions menu for a liveblog, with Edit picked out" src="/screenshots/guides/end-a-coverage-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Set the status to Ended

Under **Status**, choose **Ended**. If the site renamed the statuses, choose the one that replaced "Ended".

<Screenshot label="The Edit Liveblog panel with Status set to Ended" src="/screenshots/guides/end-a-coverage-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Save

Select **Save**. The message "Changes saved." appears.

</Step>
</Steps>

## What happens

- The liveblog takes no new entries. **Add Entry** is disabled, and Slack messages are ignored.
- Its entries are locked. They can't be published, pinned, unpinned, trashed, archived, reassigned, or turned into breakout posts.
- Feeds stop checking for new entries. Readers with the page open see the ended notice at the next check.
- The Follow Coverage button no longer appears.
- Ticker, Flash, and Alert feeds disappear.
- Feeds in other layouts stay on the page and can show an ended notice.

To reopen the liveblog, set its status back to **Live**.

## Choose what readers see

The Rolling Coverage block has an **Ended** panel. Its title shows the site's label for an ended liveblog. Set these options on each block that shows the liveblog.

<Steps>
<Step>

### Select the block

In the editor, select the Rolling Coverage block and open the **Ended** panel.

<Screenshot label="The Rolling Coverage block settings, with the Ended panel and its When ended options picked out" src="/screenshots/guides/end-a-coverage-3.webp" width={3024} height={1964} />

</Step>
<Step>

### Choose what the block does

Set **When ended**:

- **Show** keeps the feed on the page.
- **Hide** removes the whole block.

</Step>
<Step>

### Set the notice

With **When ended** on **Show**, set **Notice** to **Show** or **Hide**. When it shows, **Notice text** sets the wording. Left empty, the block says coverage of the story has concluded and the feed is archived.

</Step>
<Step>

### Add a link

With **Notice** on **Show**, set **Link** to **Show** to add a link in the notice, such as to a wrap-up story. Set **URL** and **Link text**.

Left empty, **URL** goes to the liveblog's latest breakout post, if there is one, and **Link text** reads "Read more".

</Step>
</Steps>

Readers who already have the page open see the notice at the next check for updates. The notice uses the settings from when the page loaded, so a change to its wording or link reaches them only after a reload.

Ticker, Flash, and Alert set **When ended** to **Hide** when you pick them.
