A layout sets how a feed looks: the spacing, colors, type, and which parts of each entry show. This page lists the 13 built-in layouts so you can pick the right one.

## Choose a layout

<Steps>
<Step>

### Open the layout window

Add the Rolling Coverage block and pick a coverage. Select **Choose**. The **Choose a layout** window opens, with a preview of each layout.

To change the layout of a block that already has one, select **Change Layout** in the **Layout** panel instead.

<Screenshot label="The Choose a layout window, showing a preview of each layout" src="/screenshots/guides/layouts-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Select a layout

Select the layout that suits the page. The block shows the coverage's entries in that layout.

</Step>
</Steps>

The first time an Author, Editor, or Administrator picks a built-in layout, the site saves it as a shared layout. The next guide covers [editing a shared layout](/docs/guides/edit-a-layout/).

## The built-in layouts

| Layout | What it looks like | Where it suits |
| --- | --- | --- |
| Bulletin | The default. Entries stacked with their time, title, content, and a Share button. | A full live blog page. |
| Stream | Entries without titles, each headed by the author's photo, name, and how long ago it was posted. | Many short updates, such as a press conference or a court hearing. |
| Rail | Entries along a timeline, each signed by its author. | Events where the order and gaps between updates matter, such as a storm. |
| Clock | Each entry starts with the time it was posted and is signed by its author. | Updates where the time is the point, such as election results or travel delays. |
| Margin | Each entry split in two: a margin with the time, title, and author, and the content beside it. | Long-running stories with headlines readers scan down the side. |
| Minute | Compact entries that show only their content. | Minute-by-minute coverage, such as a game. |
| Byline | Each entry signed by its author's photo and name. | Coverage with several reporters, where who filed each entry matters. |
| Ticker | A strip with the coverage's status and name beside the latest headlines. | The homepage, under the header, to point readers to breaking news. |
| Split | The full feed beside a column that holds every pinned entry. | A coverage page that leads with a pinned summary, such as "What we know". |
| Wire | A narrow list of the five latest entries, ending in a link to the coverage page. | A sidebar or another narrow column. |
| Digest | A bordered box with the coverage name, the three latest entries, and a link to the coverage page. | A sidebar, or a box inside a related story. |
| Flash | A full-width bar in the site's accent color with the latest entry and a link to the coverage page. | The site header, so a major breaking story shows on every page. |
| Alert | A box with the coverage's status, its name, and a link to the coverage page. It shows no entries. | Inside a related story, to point readers to the live coverage. |

## Layouts that show only the latest entries

Ticker, Wire, Digest, and Flash show only the newest entries. Picking one sets **Show** to **Latest** and chooses a matching **Number of entries**. Alert shows no entries, but also sets **Show** to **Latest**.

These layouts have no ads and load no older entries. Pinning doesn't apply to them.

Ticker, Flash, and Alert also set **When ended** to **Hide**. They disappear from the page once the coverage ends. See [End a coverage](/docs/guides/end-a-coverage/).

## Authors and titles

Stream, Rail, Clock, Margin, Split, and Byline show each entry's author. In the block settings, **Author name** and **Author avatar** show or hide the name and the picture, each on its own.

Rail, Clock, Margin, and Split hide the picture when you pick them. Stream and Byline show it.

An entry posted by the Slack bot shows no author until it is reassigned to a reporter. See [Post from Slack](/docs/guides/slack/).

Stream, Minute, and Flash don't show entry titles. The exception is a title taken from the first line of a Slack message, when the site has turned that on.
