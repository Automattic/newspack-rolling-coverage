By the end of this page, the coverage will have its first published entries, and you will know how to pin the most important one.

This page covers adding entries from the dashboard. Entries can also come from a Slack channel; an Administrator sets that up under **Rolling Coverage > Slack Connection**, covered in the Guides.

## Write an entry

<Steps>
<Step>

### Open the coverage's entries

In **Rolling Coverage > All Coverages**, select the coverage's row. Its list of entries opens.

<Screenshot label="A coverage's entries list, Add Entry button highlighted" />

</Step>
<Step>

### Add an entry

Select **Add Entry**. An editor opens over the list.

</Step>
<Step>

### Write the update

Add a title if the update needs one, then write it below. Entries work like posts: add text, images, video, or embeds with the same blocks.

<Screenshot label="Add Entry editor with a title and a short paragraph" />

</Step>
<Step>

### Publish it

Select **Publish**. The entry goes live on every page that shows the coverage, and readers see it without reloading.

To come back to it later, select **Save Draft** instead. Contributors see **Submit for Review**, so an editor can check the entry before it goes out.

</Step>
</Steps>

New entries appear at the top of the list. The list updates by itself, so entries added by other people show up while you work.

## Change an entry

Open the entry's row actions:

- **Quick Edit** reopens the same editor over the list.
- **Edit** opens the entry in the full WordPress editor.
- **Move to Draft** takes a published entry off the site.
- **Trash** removes it.

## Pin the most important entry

A pinned entry stays at the top of the feed, above newer entries, until you unpin it. Use it for the update every reader needs, such as a road closure or an evacuation order.

In the entry's row actions, select **Pin**. The message "Entry pinned." appears, and the list marks the entry as pinned. To undo it, select **Unpin**.

<Screenshot label="Entry row actions menu with Pin highlighted" />

Pinning needs an Editor or Administrator account.
