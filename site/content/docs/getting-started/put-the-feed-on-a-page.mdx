---
title: Put the feed on a page
description: Add the Rolling Coverage block to a page, choose a layout, and publish the live feed.
---

By the end of this page, readers will see the coverage on a page of the site, with new entries appearing as they're published.

<Steps>
<Step>

### Add the block

Open the page or post that should show the coverage. Add a block and search for "Rolling Coverage".

<Screenshot label="Block inserter with Rolling Coverage in the search results" />

</Step>
<Step>

### Choose the coverage

In the block, type the coverage's name in **Search for a coverage…** and select it from the list.

</Step>
<Step>

### Pick a layout

Select **Choose**. The **Choose a layout** window opens. Select the layout that suits the page.

Bulletin suits a full live blog page. Shorter layouts, such as Ticker or Flash, suit a homepage or a sidebar.

<Screenshot label="Choose a layout window showing the layout previews" />

</Step>
<Step>

### Make this the main page

If this page is where the coverage lives, open the block settings. In the **Coverage** panel, select **Use This Page**. Links to entries, including shared ones, now open here.

<Screenshot label="Block settings, Coverage panel with Use This Page highlighted" />

</Step>
<Step>

### Publish the page

Publish or update the page as usual. The feed shows the published entries, and new ones appear at the top while readers are on the page.

<Screenshot label="Published page showing the coverage in the Bulletin layout" />

</Step>
</Steps>

## What readers see

The feed checks for new entries every 30 seconds by default. New entries appear at the top. A reader who has scrolled down sees a button such as "3 new entries" instead, so the page doesn't jump while they read.

## Change the look later

To try another layout, select the block and choose **Change Layout** in the **Layout** panel. The Guides cover editing a layout and making a new one.
