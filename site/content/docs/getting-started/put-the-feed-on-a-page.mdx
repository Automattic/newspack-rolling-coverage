title: Put the feed on a page
description: Add the Rolling Coverage block to a page, choose a layout, and publish the live feed.
---

By the end of this page, readers will see the coverage on a page of the site, with new entries appearing as they're published.

<Steps>
<Step>

### Add the block

Open the page or post that should show the coverage. Add a block and search for "Rolling Coverage".

<Screenshot label="The block inserter with Rolling Coverage in the search results" src="/screenshots/getting-started/put-the-feed-on-a-page-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Choose the coverage

In the block, type the coverage's name in **Search for a coverage…** and select it from the list.

</Step>
<Step>

### Pick a layout

Select **Choose**. The **Choose a layout** window opens. Select the layout that suits the page.

Bulletin suits a full live blog page. Shorter layouts, such as Ticker or Flash, suit a homepage or a sidebar.

<Screenshot label="The Choose a layout window, showing a preview of each layout" src="/screenshots/getting-started/put-the-feed-on-a-page-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Make this the main page

If this page is where the coverage lives, save the page as a draft first. **Use This Page** stays disabled until the page has an address. Then open the block settings. In the **Coverage** panel, select **Use This Page**. After you save the page again, links to entries, including shared ones, open here.

<Screenshot label="The block settings, with the Use This Page button in the Coverage panel picked out" src="/screenshots/getting-started/put-the-feed-on-a-page-3.webp" width={3024} height={1964} />

</Step>
<Step>

### Publish the page

Publish or update the page as usual. The feed shows the published entries, and new ones appear at the top while readers are on the page.

<Screenshot label="The published Storm Ingrid page on the site, showing the live coverage in the Clock layout with the pinned entry first" src="/screenshots/getting-started/put-the-feed-on-a-page-4.webp" width={3024} height={1964} />

</Step>
</Steps>

## What readers see

The feed checks for new entries as soon as the page opens, then every 30 seconds by default. New entries appear at the top. A reader who has scrolled down sees a button such as "3 new entries" instead, so the page doesn't jump while they read.

## Change the look later

To try another layout, select the block and choose **Change Layout** in the **Layout** panel. The Guides cover editing a layout and making a new one.
