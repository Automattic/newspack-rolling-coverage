---
title: Create your first liveblog
description: Set up a liveblog for a developing story, ready for its first entries.
---

By the end of this page, you will have a liveblog for the story you're following, ready for entries.

You need an Editor or Administrator account to create a liveblog.

<Steps>
<Step>

### Open All Liveblogs

In the dashboard, go to **Rolling Coverage > All Liveblogs**. The list shows every liveblog on the site, with its number of entries and its status.

<Screenshot label="The All Liveblogs list, with the Add Liveblog button picked out" src="/screenshots/getting-started/create-your-first-coverage-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Add a liveblog

Select **Add Liveblog**. A panel opens on the right.

</Step>
<Step>

### Fill in the details

- **Name**: the title readers see, such as "Storm Ingrid: live updates". This is the only field you must fill in.
- **Description**: a note for the newsroom. Readers never see it.
- **Canonical URL**: the page readers land on when they open a link to one of the entries. Leave it empty for now; you can set it when you put the feed on a page.
- **Status**: leave it on **Live**.
- **Advertising**: leave it on **Enabled**, unless the story is sensitive and should run without ads.

<Screenshot label="The Add Liveblog panel with a name and a short description filled in, Status on Live and Advertising on Enabled" src="/screenshots/getting-started/create-your-first-coverage-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Save it

Select **Add**. The panel closes, the message "Liveblog added." appears, and the new liveblog shows in the list.

</Step>
</Steps>

## Change the status later

When the story goes quiet or ends, change its status. In **All Liveblogs**, open the liveblog's row actions and select **Edit**. Choose **Paused** or **Ended**, then select **Save**.

<Callout type="warn" title="Ending a liveblog">
An ended liveblog takes no new entries, and feeds stop checking for updates. Set it back to **Live** to add entries again.
</Callout>
