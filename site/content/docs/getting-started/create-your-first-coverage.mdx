---
title: Create your first coverage
description: Set up a coverage for a developing story, ready for its first entries.
---

By the end of this page, you will have a coverage for the story you're following, ready for entries.

You need an Editor or Administrator account to create a coverage.

<Steps>
<Step>

### Open All Coverages

In the dashboard, go to **Rolling Coverage > All Coverages**. The list shows every coverage on the site, with its number of entries and its status.

<Screenshot label="The All Coverages list, with the Add Coverage button picked out" src="/screenshots/getting-started/create-your-first-coverage-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Add a coverage

Select **Add Coverage**. A panel opens on the right.

</Step>
<Step>

### Fill in the details

- **Name**: the title readers see, such as "Storm Ingrid: live updates". This is the only field you must fill in.
- **Description**: a note for the newsroom. Readers never see it.
- **Canonical URL**: the page readers land on when they open a link to one of the entries. Leave it empty for now; you can set it when you put the feed on a page.
- **Status**: leave it on **Live**.
- **Advertising**: leave it on **Enabled**, unless the story is sensitive and should run without ads.

<Screenshot label="The Add Coverage panel with a name and a short description filled in, Status on Live and Advertising on Enabled" src="/screenshots/getting-started/create-your-first-coverage-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Save it

Select **Add**. The panel closes, the message "Coverage added." appears, and the new coverage shows in the list.

</Step>
</Steps>

## Change the status later

When the story goes quiet or ends, change its status. In **All Coverages**, open the coverage's row actions and select **Edit**. Choose **Paused** or **Ended**, then select **Save**.

<Callout type="warn" title="Ending a coverage">
An ended coverage takes no new entries, and feeds stop checking for updates. Set it back to **Live** to add entries again.
</Callout>
