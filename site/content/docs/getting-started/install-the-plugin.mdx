title: Install the plugin
description: Add Rolling Coverage to a WordPress site and find it in the dashboard.
---

By the end of this page, Rolling Coverage will be active on the site and its menu will be in the dashboard.

<Callout title="On a Newspack site?">
Contact the Newspack support team. They install and set up Rolling Coverage for you, so you can skip to [Create your first coverage](/docs/getting-started/create-your-first-coverage/).
</Callout>

## Before you start

- WordPress 7.0 or later, and PHP 8.0 or later.
- An Administrator account on the site.

## Install it

<Steps>
<Step>

### Download the plugin

Open the [Rolling Coverage releases page](https://github.com/Automattic/newspack-rolling-coverage/releases) on GitHub. Under the latest release, download `newspack-rolling-coverage.zip`. Keep the file zipped.

<Screenshot label="The newspack-rolling-coverage.zip file under Assets on the latest GitHub release, picked out" src="/screenshots/getting-started/install-the-plugin-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Upload it to the site

In the dashboard, go to **Plugins > Add Plugin** and select **Upload Plugin**. Choose the zip file, then select **Install Now**.

<Screenshot label="The Add Plugins screen with the Upload Plugin panel open, showing the Choose file button and Install Now" src="/screenshots/getting-started/install-the-plugin-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Activate it

When the upload finishes, select **Activate Plugin**. The plugin appears as **Newspack Rolling Coverage** in the plugins list.

</Step>
<Step>

### Find the Rolling Coverage menu

A **Rolling Coverage** menu appears in the dashboard sidebar. It holds **All Coverages**, where all the work happens. Administrators also see **Slack Connection** and **AI**.

<Screenshot label="The dashboard sidebar with the Rolling Coverage menu open, showing All Coverages, Slack Connection, and AI, picked out" src="/screenshots/getting-started/install-the-plugin-3.webp" width={3024} height={1964} />

</Step>
</Steps>
