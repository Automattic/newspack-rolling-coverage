---
title: Blocks
description: The blocks that come with Rolling Coverage.
---

Rolling Coverage adds these blocks to the editor. Each one will get its own page here.

- **Rolling Coverage**: the live feed. Shows a coverage's entries in a layout and adds new ones as they're published.
- **Coverage Status**: shows whether a coverage is Live, Paused, or Ended.
- **Follow Coverage**: lets readers follow a coverage and get a notification for new entries.
- **Update Timer**: tells readers when the feed next checks for new entries.
- **Check for Updates**: a button readers press to load new entries. Goes inside a Rolling Coverage layout.
- **Load More**: the button that loads older entries. Goes inside a Rolling Coverage layout.
