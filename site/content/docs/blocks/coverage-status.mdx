---
title: Coverage Status block
description: A badge that shows whether a liveblog is Live, Paused, or Ended.
---

The Coverage Status block shows whether a liveblog is Live, Paused, or Ended, as a small badge. It can also show when the liveblog last got a new entry, such as "Updated 2 minutes ago".

## Where to use it

- **Next to a headline.** Add it to a page or template, beside the title or in a header, so readers see at a glance whether the story is still moving.
- **Inside a Rolling Coverage layout.** It shows that block's liveblog, and the **Liveblog** panel is hidden.

To show readers when the page next checks for new entries, add an [Update Timer](/docs/blocks/update-timer/) next to the badge.

## Settings

### Liveblog panel

The panel appears only when the block is outside a Rolling Coverage block.

| Setting | What it does |
| --- | --- |
| **Automatic** | Shows the liveblog on this page, or a breakout post's liveblog. It uses the first Rolling Coverage block in the page's content, not one in the site's template. |
| **Custom** | Always shows the liveblog you pick. |

Automatic works on single posts and pages only, not on archives or password-protected posts. On those, choose **Custom**. With no liveblog to show, the block shows nothing on the site.

### Settings panel

| Setting | Options | What it does |
| --- | --- | --- |
| **Labels** | Default, Custom | **Default** uses the site-wide labels. **Custom** shows a field for each status: **Live label**, **Paused label**, and **Ended label**. An empty field uses the site-wide label. |
| **Last updated** | Show, Hide | Shows "Updated … ago" next to the badge while the liveblog is live and has a published entry. The default is **Hide**. |
| **When ended** | Show, Hide | **Hide** removes the block from the site once the liveblog ends. The default is **Show**. |
| **Dot** | Show, Hide | Turns the dot on the Live badge on or off. The default is **Show**. |

Editors and administrators set the site-wide labels in **Rolling Coverage > All Liveblogs**. Select **Settings**, then **Coverage Status**.

<Screenshot label="The block settings, Settings panel, with Labels and Last updated picked out" src="/screenshots/blocks/coverage-status-3.webp" width={3024} height={1964} />

### Colors

In the **Styles** tab, under **Color**, set **Live background**, **Paused background**, and **Ended background**. The text color is chosen for contrast. The **Text color** setting changes the "Updated … ago" text.

## What readers see

A badge that reads Live, Paused, or Ended, and optionally the "Updated … ago" text. A Live badge pulses when the dot is on.

The badge changes without a page reload when a Rolling Coverage block for the same liveblog is on the same page. Without one, it keeps the status it had when the page loaded.
