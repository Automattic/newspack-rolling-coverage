---
title: Update Timer block
description: Tell readers when the feed next checks for new entries.
---

The Update Timer block shows readers when a live coverage next checks for new entries. It reads "Next check in 7s" with a small ring that fills as the check nears. While the check runs, it reads "Checking…" and the ring spins. When the check brings new entries, it reads a count such as "2 new entries" for a few seconds.

## Where to use it

- **Next to the Live badge.** Add it to a page or template, beside a [Coverage Status](/docs/blocks/coverage-status/) block, so readers can see the page keeps itself up to date.
- **Inside a Rolling Coverage layout.** Add it to the feed or to a group at the coverage level, such as the layout's header. It follows that block's coverage. It can't go inside an entry or the pinned entry.

It counts down a Rolling Coverage block's own checks, so a Rolling Coverage block for the same coverage must be on the page.

## Settings

### Coverage panel

The panel appears only outside a Rolling Coverage block.

| Setting | What it does |
| --- | --- |
| **Automatic** | Counts down to the next check of the coverage on this page, or a breakout post's coverage. |
| **Custom** | Always counts down for the coverage you pick. |

### Settings panel

| Setting | Options | What it does |
| --- | --- | --- |
| **Ring** | Show, Hide | The ring fills beside the countdown until the next check, then spins while the check runs. **Hide** leaves the text on its own. The default is **Show**. It doesn't spin for readers whose device is set to reduce motion. |

The ring and text take the block's text color. In the **Styles** tab, the **Typography** settings change the text size, and the ring scales with it.

## When it doesn't appear

The timer stays hidden while there is nothing to count down to:

- The coverage is paused or has ended. If it goes live again while the page is open, the timer comes back.
- The layout holds a [Check for Updates](/docs/blocks/check-for-updates/) block, so the feed checks only when readers ask.
- There is no Rolling Coverage block for its coverage on the page.

## What readers see

The seconds count down once a second, and the ring fills steadily over the same wait. Readers whose device is set to reduce motion see the ring fill, but while the check runs it shows full and still. When the check ends, the timer shows what it found, then starts again.

After a failed check, the page waits longer before it tries again, up to 5 minutes, and the timer counts down that longer wait.

Screen readers don't hear the countdown or the ring. The Rolling Coverage block already announces new entries.
