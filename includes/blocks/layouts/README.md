# Built-in layouts: server copies

Generated by `npm run build:layouts` from the templates in `src/blocks/rolling-coverage/`. Don't edit these files: change the template and run the command again. `npm test` fails while they are out of date.

The `{{…}}` tokens are what the editor takes from the site; `Layout_Templates` fills them in. See "Server copies" in [`src/blocks/rolling-coverage/DEVELOPMENT.md`](../../../src/blocks/rolling-coverage/DEVELOPMENT.md#layouts).
